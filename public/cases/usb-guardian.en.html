USB Guardian · Windows Endpoint Security

A desktop application that monitors removable devices, alerts users and applies endpoint response actions on Windows computers.

Project context

The application runs in the background with administrator privileges and monitors USB storage and mobile devices connected to the computer.

Solution design

The monitor detects changes through logical drives and Plug and Play device information. When a device requires control, the application alerts the user, can isolate outbound network connectivity through Windows Firewall and can start a configured shutdown response.

Key capabilities

  • Monitor USB and removable storage connections
  • Detect devices through logical-drive and Plug and Play checks
  • Alert users to security events
  • Integrate response actions with Windows Firewall and shutdown workflow
  • Package the desktop application for Windows deployment

Role & contribution

Designed the solution and developed the desktop security application, including device monitoring, Windows integration and deployment packaging.
