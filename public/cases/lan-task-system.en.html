LAN Task Management System

An internal application for assigning work, tracking progress and recording completion in one workflow.

JavaSpring BootThymeleafBootstrap 5AJAXSQLiteOn-premise LAN
GitHub ↗

Project context

Designed as a server-and-client application on a local network, with distinct interfaces for task coordinators and recipients.

Solution design

The server manages personnel, issues or recalls tasks and monitors overall status. Clients receive assignments, acknowledge them and submit completion reports. AJAX polling refreshes task status without reloading the page.

Key capabilities

  • Create, issue and recall tasks
  • Acknowledge assignments and update progress
  • Submit completion reports from client workstations
  • Review task status from a central server interface
  • On-premise LAN deployment with SQLite storage

Role & contribution

Designed the solution and built the full-stack application, including the server/client interfaces, workflow and internal deployment approach.
