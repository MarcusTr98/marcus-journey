Project overview

A concise overview of the improvement approach.

Problem

Recurring machine and tool failures disrupted work and prolonged on-line response.

Current state

QC tools grouped failure records. Shop-floor observation found equipment that had gone too long without cleaning. The simulation covers 40 machines, with 20–50 minutes of daily downtime per machine and some failures lasting 2–4 hours.

Root cause

QC analysis and observation identified missed cleaning. Some failure modes needed clear troubleshooting guidance and standard work.

Countermeasures

Use QC tools to classify failures, introduce a cleaning check sheet, define standard troubleshooting steps, and align shift handovers.

Improvement results

The simulated scenario shows a 50% reduction in the failure index after standardizing cleaning, troubleshooting, and handover.

Sustain

Train operators, maintain the check sheet and standard work at the machine, verify cleaning and handover, and update guidance when new failure modes appear.

Project role

Classified failures with QC tools, identified cleaning gaps, prepared check sheets and standard work, and supported adoption and handover.
